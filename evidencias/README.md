# Evidencias de Fase 2

## Capturas del navegador: pendientes

La herramienta de control del navegador se detuvo al no poder determinar con certeza la URL activa. No se adjuntan capturas simuladas ni se considera completo este requisito visual.

Para completar la evidencia en esta computadora:

1. Abrir `https://localhost:8443` en Brave, Chrome o Edge.
2. Abrir el icono de información/controles junto a la dirección y mostrar **La conexión es segura**, con la página AutoRent visible detrás. Guardar la captura completa como `01-https-seguro.png` en esta carpeta.
3. Abrir `https://localhost:8443/api/vehiculos`, mostrar la dirección HTTPS y la respuesta JSON del negocio. Guardar como `02-api-vehiculos.png`.
4. Agregar las capturas a Git y actualizar este apartado para indicar la comprobación visual real.

El certificado público debe estar registrado como confiable en el equipo que toma las capturas, según el README principal. No omitir advertencias ni utilizar opciones de ignorar errores TLS.

## Verificación técnica

Consultar [verificacion-fase2.md](verificacion-fase2.md) para los resultados de la ejecución local. Las comprobaciones por HTTPS y los registros complementan las capturas; no sustituyen la evidencia visual que pide la rúbrica.
